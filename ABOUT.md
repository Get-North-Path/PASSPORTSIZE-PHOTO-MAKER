# What is Passport Size?

**Passport Size** is the public name of [GetNorthPath Passport Photo](https://passportsize.getnorthpath.com/): a free, in-browser passport, visa, and ID photo maker. The live site is hosted at [passportsize.getnorthpath.com](https://passportsize.getnorthpath.com/). Product copy also uses “GetNorthPath Passport Photo” and “GetNorthPath Photo.”

This GitHub repository is the **public information hub** for that product. It documents features, pages, workflows, photo requirements, supported countries and documents, and official sources. It is **not** the application source-code repository and does not contain implementation, APIs, or private infrastructure.

---

## What Passport Size is

A **free DIY photo tool** for people who need a photo that matches a published government specification:

- Pick a **country and document** (passport, visa, citizenship, residence card, or immigration upload)
- Process a **front-facing photo in the browser** (no image upload to GetNorthPath)
- See **head height in millimetres** against the published range
- Replace the background with the **shade that format requires**
- Download a **print** file (true DPI) and, where rules exist, a **digital** file (pixels and kilobytes)

As of the public formats dataset dated **24 September 2026**, the product covers **54 countries** and **62 document formats**.

## How it relates to GetNorthPath

[GetNorthPath](https://www.getnorthpath.com) is a Canadian immigration platform: **AI-powered features and free DIY tools**, built for immigrants by immigrants. The company line is **AI for All**   immigration should be accessible, not only for people who can pay thousands for help.

Passport Size is one of GetNorthPath’s **free public tools**. The about page states it was built because applications kept being delayed over a photo: millimetre head height, country-specific backgrounds, and digital file-size ceilings that most phone photos miss.
