## Editor capabilities (verified from live copy)

- MediaPipe-style **face landmarks** and a **selfie segmenter**, downloaded from public CDNs on first use, then cached
- Measurement of **chin, eye line, and true crown (hair included)**
- **Compliance panel** (head height vs published range, and related checks)
- **Straighten / head size / position sliders** when automatic crop is wrong
- **Print vs digital** presets where digital rules exist
- **JPEG quality search** to fit kilobyte ceilings; padding described for floors (for example Chinese 40 KB minimum)
- **Print sheets** with copy counts for 4×6, 5×7, A4, Letter
- **Email to unlock download**; no watermark; no download limit stated
- Optional **written feedback** (`/api/feedback` accepts a note, not a photo)
