# Countries

**Live:** [https://passportsize.getnorthpath.com/passport-photo-by-country](https://passportsize.getnorthpath.com/passport-photo-by-country)

**Nav:** Countries

One page per country (or Schengen Area) under `/passport-photo/{slug}`. Hub copy: **54 countries** and **13 distinct print formats**. Head height is chin to crown, hair included.

These pages are **photo specifications**, not embassy visa-instruction manuals.

## Shared outer sizes (hub copy)

The country hub groups 39 formats at **35×45 mm**, five at **50.8×50.8 mm**, two at **33×48 mm**, plus one-off sizes. Sharing an outer size is not enough: export separately so head height can differ.
